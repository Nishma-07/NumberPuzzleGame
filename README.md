# 🧩 Number Puzzle Game

A simple interactive **3×3 Number Puzzle Game** built using Java Swing. The game challenges players to rearrange shuffled numbered tiles into the correct order by moving tiles into the empty space.

## 📌 About the Project

The Number Puzzle Game is a desktop-based application developed using Java and Swing. It provides a simple graphical interface where players can move numbered tiles, track their moves, and monitor the time taken to solve the puzzle.

The objective is to arrange the numbers from **1 to 8 in ascending order**, leaving the last cell empty.

## ✨ Features

- **3×3 Puzzle Grid** – Interactive grid containing 8 numbered tiles and one empty space.
- **Tile Movement** – Move a tile into the empty space if it is adjacent.
- **Shuffle** – Randomly rearranges the puzzle using valid tile movements.
- **Move Counter** – Tracks the number of moves made by the player.
- **Timer** – Records the time taken to solve the puzzle.
- **Win Detection** – Automatically detects when the puzzle is solved.
- **Congratulations Message** – Displays the number of moves and time taken upon completion.
- **Automatic Restart** – Starts a new shuffled puzzle after successfully completing the game.

## 🛠️ Technologies Used

- **Java** – Programming language
- **Java Swing** – GUI development
- **AWT** – Layouts, fonts, and graphical components
- **Random** – Random tile shuffling

## 🎮 How to Play

1. Launch the game.
2. Click the **Shuffle** button to rearrange the tiles.
3. Move a tile by clicking it if it is adjacent to the empty space.
4. Arrange the numbers in the correct order from 1 to 8.
5. Keep track of your moves and time.
6. Solve the puzzle to win!

### 🎯 Winning Arrangement

    1  2  3
    4  5  6
    7  8  _

## ⚙️ How to Run

### Prerequisites

- Java JDK installed (Java 8 or later recommended)
- Any Java IDE (VS Code, IntelliJ IDEA, or Eclipse) or terminal

### Run using the terminal

"1. Clone the repository"

```bash
git clone https://github.com/your-username/NumberPuzzleGame.git
```

"2. Navigate to the project folder"

```bash
cd NumberPuzzleGame
```

"3. Compile the program"

```bash
javac PuzzleGame.java
```

"4. Run the game"

```bash
java PuzzleGame
```
